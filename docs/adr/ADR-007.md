# ADR-007: Antd (Ant Design) over MUI/Chakra

- **Status**: Accepted
- **Date**: 2024-06-01
- **Deciders**: Technical Lead, Architects

## Context

The gym system targets the Vietnamese market where Ant Design (Antd) has strong adoption and community support. The application requires data-heavy interfaces including membership tables with sorting/filtering, booking calendars, and complex forms with validation. Vietnamese locale support out of the box is essential for date pickers, pagination, and form validation messages. MUI and Chakra are less well-known in the Vietnamese developer ecosystem.

## Decision

Use Antd 6 as the primary UI component library with Tailwind CSS for custom styling and layout. Configure Antd's ConfigProvider with Vietnamese locale. Use dayjs as the date library (Antd 6 default).

## Consequences

- (+) Rich component set covering tables, forms, date pickers, calendars, and modals — reducing custom development.
- (+) Built-in Vietnamese locale for all components (date formats, pagination text, validation messages).
- (+) Excellent Table component with built-in sorting, filtering, pagination, and column management.
- (+) Strong Form component with declarative validation rules.
- (-) Large bundle size (~80KB gzipped for full library) — mitigated by tree-shaking and individual component imports.
- (-) Customization requires CSS variable overrides or ConfigProvider theme tokens — less intuitive than MUI's sx prop.
- (-) Component API is opinionated — integrating non-Antd libraries (e.g., custom inputs) can be friction-prone.

## Compliance

All UI components should be imported from Antd where applicable. Custom styling must use Tailwind utility classes. Theme customization must use ConfigProvider theme tokens, not CSS overrides. Antd icons should be imported individually to avoid bundle bloat.
