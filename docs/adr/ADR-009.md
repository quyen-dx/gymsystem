# ADR-009: GHN (Giao Hàng Nhanh) for Shipping

- **Status**: Accepted
- **Date**: 2024-06-01
- **Deciders**: Technical Lead, Architects

## Context

The gym system includes an e-commerce component for selling supplements, equipment, and merchandise. The target market is Vietnam, where GHN (Giao Hàng Nhanh) is the leading domestic shipping provider with the widest coverage network. Requirements include real-time tracking, COD (Cash on Delivery) support, rate calculation, and automated pickup scheduling. Other providers (GHTK, Viettel Post, VNPost) have weaker API documentation or limited coverage in key urban areas.

## Decision

Use GHN API for all shipping logistics including rate calculation, pickup requests, order tracking, and delivery confirmation. Implement webhook endpoints for real-time tracking status updates. Use GHN's address master data for checkout address validation.

## Consequences

- (+) Best coverage in Vietnam — GHN reaches 63 provinces with competitive delivery times.
- (+) Well-documented REST API with sandbox environment for testing.
- (+) Webhook support enables real-time tracking status updates without polling.
- (+) Built-in COD support with automated remittance.
- (-) Vietnam-only — no support for international shipping; alternate solutions required for cross-border orders.
- (-) Dependency on third-party API availability — requires circuit breaker and fallback logic.
- (-) API rate limits require careful queuing for bulk order processing.

## Compliance

All shipping API calls must use the GHN service abstraction layer with retry logic. Tracking webhooks must be verified via GHN's signature mechanism. Shipping fees must be calculated server-side and cached to avoid redundant API calls. API tokens must be stored in environment variables.
