# ADR-004: Google Gemini 2.5 Flash as Primary AI Provider

- **Status**: Accepted
- **Date**: 2024-06-01
- **Deciders**: Technical Lead, Architects

## Context

The gym system requires AI-powered features including a real-time chat assistant for member inquiries, workout plan generation, and nutrition advice. Cost-effectiveness and low latency are critical for real-time interactions. Vietnamese language support is a non-negotiable requirement for the target user base. Function calling capability is needed for tool integration (booking creation, membership lookups). Multiple providers are evaluated to ensure availability and cost optimization.

## Decision

Use Google Gemini 2.5 Flash as the primary AI provider for its cost-to-performance ratio. Configure Claude 3.5 Haiku via OpenRouter as the primary fallback and Groq Llama 3 as a secondary fallback. Implement a circuit breaker pattern that routes to fallbacks on timeout or error.

## Consequences

- (+) Gemini 2.5 Flash costs approximately $0.30 per 1M tokens — significantly cheaper than GPT-4 or Claude 3 Sonnet.
- (+) Sub-1 second latency enables real-time streaming chat experiences.
- (+) Strong Vietnamese language capabilities across all tested domains.
- (+) Native function calling support for tool integration.
- (-) Vendor lock-in risk — mitigated by the fallback chain and an abstraction layer over provider APIs.
- (-) Gemini may refuse certain gym or health advice due to safety filters — fallback providers handle these cases.
- (-) Two fallback providers add integration and testing overhead.

## Compliance

All AI interactions must go through a unified AI service abstraction. Provider responses must be logged for audit and quality monitoring. Fallback thresholds and circuit breaker parameters must be environment-configurable.
