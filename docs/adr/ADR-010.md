# ADR-010: Socket.io over Server-Sent Events (SSE)

- **Status**: Accepted
- **Date**: 2024-06-01
- **Deciders**: Technical Lead, Architects

## Context

The gym system requires real-time bidirectional communication for multiple features: AI chat message streaming (client sends prompts, server streams responses), push notifications (membership expiry, booking reminders), and live booking updates (trainer availability changes, slot releases). SSE supports only server-to-client communication and lacks built-in reconnection logic. WebSocket provides bidirectional communication but requires manual implementation of reconnection, room management, and fallback transports.

## Decision

Use Socket.io for all real-time communication. Implement JWT authentication on the handshake. Use room-based event routing for targeted message delivery (per-user rooms for notifications, per-booking rooms for live updates).

## Consequences

- (+) Bidirectional communication supports both AI chat streaming and server push notifications.
- (+) Automatic reconnection with exponential backoff — critical for mobile clients with unstable connections.
- (+) Room-based multiplexing enables efficient targeted message delivery without broadcasting to all clients.
- (+) Fallback transports (long-polling, WebSocket) ensure compatibility with restrictive network environments.
- (+) Built-in acknowledgment callbacks simplify message delivery confirmation.
- (-) Additional server overhead compared to raw WebSocket or SSE — each connection maintains a session object.
- (-) WebSocket dependency may be blocked by some corporate proxies — mitigated by long-polling fallback.
- (-) Socket.io uses its own custom protocol; debugging with standard WebSocket tools is not possible.

## Compliance

All Socket.io connections must authenticate via JWT on handshake. Client-side Socket.io instances must configure reconnection options (attempts, delay). Events must follow a consistent naming convention (namespace:action, e.g., chat:message, notification:new). Rooms must be joined and left explicitly on the server.
